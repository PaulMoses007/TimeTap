# TimeTap

## Project Title
TimeTap – Attendance Management System for Chef Mezze

---

# Project Overview

TimeTap is a QR-code-based attendance management system designed for Chef Mezze Restaurant.

The purpose of the system is to replace the manual attendance process with a secure, digital solution that allows employees to check in and check out using a mobile application.

Managers can monitor attendance, approve employee registrations, and generate reports.

---

# Objectives

- Eliminate manual attendance records
- Reduce attendance errors
- Save managers' time
- Provide accurate working hour calculations
- Generate attendance reports automatically

---

# User Roles

## Employee

Can:

- Register
- Login
- Scan Restaurant QR
- Check In
- Check Out
- View Attendance History
- Update Profile

---

## Manager

Can:

- Login
- Approve Employee Registration
- Reject Employee Registration
- View Attendance
- Edit Attendance
- View Reports
- Manage Employees
